# 0010 — Web con Next.js

- **Estado:** Aceptada
- **Fecha:** 2026-09-28

## Decisión

- **Next.js (App Router) + TypeScript + Tailwind v4.**
- **Componentes:** shadcn/ui (Radix) con los tokens de `docs/design-system/tokens.json`; íconos Lucide (GUIDELINES).
- **Datos:** cliente generado (ADR 0007) + **TanStack Query**, con polling en las pantallas que lo necesitan (RNF-002).
- **Formularios:** react-hook-form + zod.
- **Mapa:** MapLibre GL JS con el protocolo PMTiles (ADR 0012).
- **Estructura por feature** (`src/features/partidos/…`), no por tipo de archivo.
- **Storybook** para los componentes del design system, con tests visuales.
- **E2E con Playwright.**
- El panel de administración de la plataforma (RF-095 a RF-099) es una sección de la web (`/admin`), no una app aparte.
- Se sirve en modo `standalone` desde el mismo VPS (ADR 0013).

## Consecuencias

- La web no tiene lógica de negocio: la API es la autoridad. La validación del cliente es solo para la experiencia.
